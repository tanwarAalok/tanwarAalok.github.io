# tanwaraalok.github.io

Personal portfolio of Aalok Tanwar, served by GitHub Pages at https://tanwaraalok.github.io/.

A single static page with no build step: `index.html` holds the markup, styles and scripts. `resume.pdf`, `og-image.png`, `robots.txt` and `sitemap.xml` sit beside it, and the portrait is `assets/images/my-avatar.png`.
